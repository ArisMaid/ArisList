# ArisList v0.5.0

## 变化

- 完善 STRM 来源解析、旁置封面与 ComicInfo XML 元数据读取、原文标题选择及远程资源准备流程。
- 普通 ZIP/CBZ 漫画目录探测缩小至 65557 字节，目录已知后的单页文件头和正文合并为一次 Range 请求。
- 漫画向前预加载默认 5 页，可在设置中调整为 5～10 页；逐张加载，失败停止，退出后取消后续任务。
- 普通远程漫画原图使用独立缓存，默认 512 MiB，支持 `STRM_PAGE_CACHE_MAX_BYTES`。超限优先淘汰旧页，24 小时未访问的页在下一次冷读取时清理，近期页受保护。
- 包含此前尚未发布的统一浅色界面、布局和交互调整，以及 STRM 诊断和密码/分卷归档准备功能。

## 升级说明

- **此版本已移除内置管理员密码与登录鉴权。** 升级前使用可信局域网、受限端口或具有认证的反向代理保护访问，原管理员密码不再构成访问保护。
- 升级前备份应用数据目录。镜像保持 `linux/amd64` 架构。
- 512 MiB 额度仅用于新的普通漫画原图缓存，不涵盖复杂归档整包、音声或旧目录中的历史缓存；旧缓存未自动批量删除。
- 不需要仅为预加载优化重新扫描全库。STRM 来源或文件内容发生变化时，按原有扫描流程更新。
- 预加载不会绕过远程限流与失败冷却；源站速度较慢时仍可能出现等待。

## 镜像

```text
ghcr.io/arismaid/arislist:v0.5.0
ghcr.io/arismaid/arislist:latest
```

在 `.env` 中指定 `ARISLIST_IMAGE=ghcr.io/arismaid/arislist:v0.5.0`，再执行 `docker compose pull` 和 `docker compose up -d`。

性能实现与抽样验证详见 [开发与验收记录](../strm-reading-performance-20261003.md)。
